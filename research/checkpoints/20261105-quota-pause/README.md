# 2026-11-05 한도 대비 중단 체크포인트

사용자 요청으로 **공용 실행 후보 4의 패키지 최종 검수까지만** 진행하고 중단했다.
전체 로드맵 완료나 제품 출시를 뜻하지 않는다. 명시적인 재개 요청 전에는 에이전트,
실험, 다음 노드를 시작하지 않는다. 네이티브 실행 슬롯은 `idle`, sequence `228`이다.

현재 `src/dfm_cli`는 기존 승인된 191파일 제품이다. 아래 `pending/`은 **제품에 합치지 않은
후보·검증기·실패 기록**이다. 일반 설치 또는 테스트 수집 경로로 추가하지 않는다.
출처와 SHA-256은 [manifest.json](manifest.json)에 기록했다. 내용이 기존 제품과 동일한
소스는 `reuse_accepted_root_files`에 원본 대응과 해시를 기록하고 중복 저장하지 않았다.

## 재개할 때 먼저 읽을 순서

1. 이 문서, 루트 `AGENTS.md`, `DELIVERY.md`, `ROADMAP.md`.
2. `pending/coordinator/dispatch.json`: 노드별 선행 조건·소유자·승인 범위.
3. 해당 노드의 `CHECKPOINT.md`, `HANDOFF.md` 또는 `HANDOFF.json`.
4. 아래 미완료 항목의 원본 근거. 로컬 `research/experiments/`는 그대로 보존되어 있다.
   다른 컴퓨터에서는 먼저 이 체크포인트 파일의 해시를 검증하고 필요한 로컬 자료를
   확보한다. 없어진 원시 로그·출력·설치본을 JSON 성공 표시로 대신하지 않는다.

## 작업자 중단 확인

Nash, Lovelace, Faraday, Einstein, Archimedes, Mill, Plato는 중단 체크포인트와
남은 실행/핸들 없음 또는 알려진 활성 실행 없음으로 보고했다. Raman은 요청 한도
오류로 종결됐으며 새 작업자를 시작하지 않았다. 그 전에 작성한 fixture 이관 동결본과
미해결 실패 기록을 보관했다. 코디네이터가 시작했던 사전검사 프로세스도 종료됐다.

## 보관 범위와 한계

Git에는 기존 제품·문서·연구 도구와 함께 선택한 미병합 코드, 테스트 코드, 작은 판정
기록, 재개 지침을 저장한다. 다운로드한 원본 저장소, 상용 설치 파일·역컴파일 자료,
가상환경, wheel, 원시 모델·NetCDF·전체 실험 로그는 기존 `.gitignore`대로 로컬에 남긴다.
체크포인트는 그 전체 자료의 대체물이 아니다. 기록 안의 절대 경로는 당시 증거 위치다.

`capture.py`는 이 중단 시점에 선택한 소스의 기록용이며, 기존 체크포인트를 덮어쓰지
않는다. 복구 시에는 각 `original_path`에 파일이 없을 때만 복사하고, 이미 다른 바이트의
파일이 있으면 먼저 변경 내용을 검토한다. 검증 없이 제품 디렉터리로 일괄 복사하지 않는다.
